# Source data and software

The model coefficients derive from Polasky et al. (2026), *Landscape efficiency frontiers for biodiversity, climate mitigation, and net economic value*, *Science* ([DOI 10.1126/science.aea9058](https://doi.org/10.1126/science.aea9058)).

The corresponding [Dryad dataset](https://doi.org/10.5061/dryad.b2rbnzsvt) is available under CC0 1.0. The `inputs/` folder contains the European analytical coefficient extract in two compressed parts. Both parts reconstruct the exact database used in the analysis. Source metadata are recorded in `inputs/SOURCE.json`.

The notebook and scripts use separately installed Python libraries listed in `requirements.txt`; these retain their respective software licenses. No copyrighted source article or supplementary PDF is distributed in the repository.
